# AGENTS.md

Guidance for coding agents and contributors. This project was generated by
`strictjava new` and uses the strictjava Java profile.

## Required gate

```bash
./gradlew --no-daemon formatCheck
./gradlew --no-daemon test
./scripts/strictjava.sh check --classpath "$(./gradlew -q strictjavaClasspath)" .
```

The strictjava command must return JSON with `"ok": true` before work is
complete. Do not suppress diagnostics or infer source edits from diagnostic prose.

## Hard constraints

- Java 25 is the target and execution toolchain.
- Packages are explicitly JSpecify-null-marked.
- No wildcard imports or `@SuppressWarnings`.
- No mutable global state.
- Avoid `Optional.get()`; handle the empty case explicitly.
- No native-code escape hatches or runtime halts.
- Enum/sealed switches name every variant instead of using `default`.
- Keep filesystem/network/process/environment/reflection effects in a narrow
  source file with the exact first-20-lines marker `// strictjava: capability`.
- Treat ignored results and resource ownership diagnostics as correctness errors.

## Reproducibility

- Use the committed Gradle 9.8.0 wrapper.
- Keep `distributionSha256Sum` in the wrapper properties.
- Dependency locking is strict; update `gradle.lockfile` intentionally with
  `./gradlew dependencies --write-locks`.
- Dependency verification is strict; update `gradle/verification-metadata.xml`
  intentionally with `./gradlew --write-verification-metadata sha256` and review it.
- Formatting uses google-java-format 1.36.1 with a pinned SHA-256.
- Do not replace exact dependency versions with ranges, `+`, snapshots, or changing modules.

## Tooling

- `./gradlew format` rewrites Java sources.
- `./gradlew formatCheck` verifies formatting.
- `./gradlew test` runs the dependency-free smoke test.
- `make check` runs strictjava using `STRICTJAVA_JAR` or a `strictjava` command on PATH.
- `./scripts/commit.sh "message"` runs the local gate and commits; `-p` also pushes.
- CI is reusable through `workflow_call` and builds the application distribution once before Docker packaging.
